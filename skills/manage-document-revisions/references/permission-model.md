# 폴더 리비전 스킬 권한 모델

## 1. 보안 목표

문서 원본 시스템의 자격정보를 AI 실행 경계에 전달하지 않는다. 외부의 사람 또는 별도 동기화 작업이 문서를 `data/before`에 배치하며, AI는 로컬 입력을 읽고 새 실행 디렉터리에만 결과를 쓴다.

## 3. 책임 분리

| 주체 | 책임 |
| --- | --- |
| 데이터 관리자 | Confluence를 포함한 원본 시스템에서 승인된 방법으로 내보내고 민감정보와 ACL sidecar를 검토한 뒤 `data/before`에 배치 |
| 스킬 실행기 | 승인 경로 해석, 입력 인벤토리, 신규 run 생성, 경로 가드, 비교와 finalization |
| Qwen 워커 | 제공된 텍스트를 분석하고 구조화된 수정 후보를 반환하며 파일·네트워크·비밀 저장소에 직접 접근하지 않음 |
| 검토자 | 비교 리포트, 인용, 변경 제안, 보안 등급을 확인하고 채택 여부 결정 |

## 4. 방어 계층

1. 운영체제 권한으로 `data/before`를 AI 실행 계정에 읽기 전용으로 제공한다.
2. 샌드박스 정책은 `data/before` 읽기와 현재 `data/after` run 쓰기만 허용한다.
3. 모든 쓰기는 경로 가드가 있는 준비·비교 도구 또는 현재 run에 한정된 편집 도구를 통한다.
4. 링크와 재해석 경로를 거부하고 정규화된 절대 경로가 승인 루트 내부인지 매번 검사한다.
5. 기존 run을 덮어쓰지 않고 finalization 이후에는 논리적으로 불변으로 취급한다.
6. 입력과 출력의 SHA-256 매니페스트 및 파일별 비교 결과를 남긴다.

스킬 지침만으로 운영체제 권한이 생기거나 강제되지는 않는다. 실제 배포에서는 전용 로컬 계정, 읽기 전용 마운트 또는 ACL, 샌드박스 allowlist를 함께 적용해야 한다.

## 5. 권장 macOS 권한

전용 실행 계정 `rag-agent`를 사용하는 경우 데이터 관리자는 before 소유권을 유지하고 실행 계정에는 읽기와 디렉터리 탐색만 부여한다. after는 실행 계정이 새 run을 만들 수 있게 하되 기존 finalized run은 관리자 검토 후 읽기 전용으로 전환한다.

운영 명령은 조직의 계정·그룹 정책에 맞춰 별도 runbook에서 확정한다. 재귀 권한 변경 전에는 반드시 해석된 절대 경로가 프로젝트의 `data/before` 또는 대상 finalized run인지 확인한다.

## 6. Confluence 경계

- Confluence 내보내기는 이 스킬과 RAG 런타임의 외부 책임이다.
- API 키, access token, cookie, base URL, 로그인 세션을 설정 스키마나 run 매니페스트에 넣지 않는다.
- 내보낸 문서는 가능하면 페이지 ID, 버전, 수정 시각, 원본 URL의 비밀정보 제거값, 보안 등급을 sidecar로 포함한다.
- sidecar가 없으면 파일 상대 경로, 수정 시각, 콘텐츠 해시를 사용하고 ACL은 가장 제한적인 기본값으로 둔다.
- 원본 시스템으로의 자동 write-back은 제공하지 않는다.
