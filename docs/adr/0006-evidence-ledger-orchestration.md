# ADR-0006: Evidence·Claim Ledger 기반 문서 오케스트레이션

- 상태: Accepted
- 결정일: 2026-08-12

런타임 품질 게이트와 제한 재작성 결정은 2026-08-17의
[ADR-0008](0008-non-blocking-quality-observation.md)로 대체됐다. Evidence·Job·결정적 조립
결정은 계속 유효하다.

## 1. 배경

기존 전체 문서 통합 수직 슬라이스는 토큰 예산 기반 map/reduce로 하나의 Markdown을 생성한다.
이 방식은 긴 최종 출력이 잘릴 수 있고, reduce 과정에서 전제조건·명령·경고가 누락되며, 내부
청크 번호가 출처 경로에 섞일 수 있다. 모델이 완성된 문서를 다시 자유롭게 작성하는 마지막
단계는 앞 단계에서 보존한 세부사항을 잃는 추가 실패 지점이다.

GUI와 재개 가능한 장기 실행을 지원하려면 대화 세션이 아니라 명시적인 Job 상태, 중간
아티팩트, 진행 이벤트가 필요하다. 기존 모델 산출물을 원본 근거로 재사용하면 오류가 증폭되므로
원본 Evidence와 파생 결과도 분리해야 한다.

## 2. 결정

1. Coordinator는 결정적인 Job 상태 머신으로 실행을 관리한다.
2. 모델 대화 세션은 상태 저장소로 사용하지 않는다. 각 모델 작업은 불변 `TaskPacket`과
   구조화된 `TaskOutput`으로 실행한다.
3. 원본에서 추출한 Evidence, 모델 파생물, 제어 메타데이터를 서로 다른 논리 저장 영역에 둔다.
4. 모든 원자적 사실·절차·명령·경고를 Claim Ledger에 기록하고 Evidence ID와 연결한다.
5. 중복은 `EXACT_DUPLICATE`, `SEMANTIC_EQUIVALENT`, `COMPLEMENTARY`,
   `CONTEXTUAL_REPEAT`, `CONFLICT`, `UNRELATED` 관계로 분류한다.
6. Coverage Matrix가 모든 필수 Claim과 원본 구조 요소를 하나 이상의 Task에 배정한다.
7. 태스크 결과는 독립적으로 검증하며 실패한 섹션만 최대 2회 제한적으로 재작성한다.
8. 최종 Markdown은 검증된 섹션을 코드가 결정적으로 조립한다. 전체 문서 자유 재작성은 하지
   않는다.
9. 품질 게이트를 통과하기 전에는 `data/after/runs`를 만들지 않는다. 중간 결과는
   `var/jobs/<job_id>`에 보관한다.
10. GUI, CLI는 같은 Application 유스케이스를 호출한다. MLX 모델은 별도 Worker 프로세스가
    소유한다.

## 3. 품질 불변 조건

- 필수 Coverage, 출처 경로 유효성, Claim-Evidence 연결은 100%여야 한다.
- 잘린 출력, 미완성 Markdown, 숨겨진 충돌, 근거 없는 사실, 원본 누락은 0건이어야 한다.
- Derived 산출물은 중복 탐색에 사용할 수 있지만 최종 사실의 Evidence가 될 수 없다.
- 벡터 검색은 후보 탐색에만 사용하고 top-k 밖의 원본을 처리 대상에서 제외하지 않는다.
- 의도적 반복은 일반 중복과 구분하며 운영 단계의 완결성을 위해 유지한다.

## 4. 결과

### 장점

- 누락과 출력 잘림을 게시 전에 결정적으로 차단한다.
- 태스크 단위 재시도와 중단 후 재개가 가능하다.
- 중복 제거와 충돌 보존의 판단 근거를 감사할 수 있다.
- GUI가 장기 실행 상태를 안정적으로 복원할 수 있다.

### 비용

- Claim 추출, 관계 판정, 검증 호출로 실행 시간이 증가한다.
- SQLite Job 저장소와 파일 아티팩트 관리가 추가된다.
- 파이프라인 단계와 계약이 기존 수직 슬라이스보다 복잡해진다.

정확성과 감사 가능성이 처리량보다 우선이므로 이 비용을 수용한다.

## 5. 대안

- 단일 map/reduce 유지: 구현은 단순하지만 누락과 마지막 단계 잘림을 해결하지 못한다.
- 대화 세션 재개: 명시적 상태와 재현성이 부족해 거부한다.
- 기존 산출물을 Evidence와 혼합: 모델 오류가 다음 실행에서 원본처럼 증폭되어 거부한다.
- 최종 문서 전체 재작성: 검증된 세부사항이 다시 유실될 수 있어 거부한다.
