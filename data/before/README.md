# 수정 전 문서 저장소

이 디렉터리는 파이프라인 입력 스냅샷이며 AI가 수정하는 작업공간이 아니다.

## 규칙

1. 데이터 관리자가 승인된 외부 절차로 문서를 배치한다.
2. 배치 완료 후 파일 내용과 상대 경로를 실행 중 변경하지 않는다.
3. AI 실행 계정에는 읽기와 디렉터리 탐색 권한만 부여한다.
4. symbolic link, junction, alias, 특수 파일을 넣지 않는다.
5. 문서 ACL을 직접 전달할 수 없으면 가장 제한적인 기본 보안 등급을 적용한다.
6. 새 스냅샷은 기존 파일을 덮어쓰기보다 새 데이터셋 디렉터리로 추가한다.
